# Results

One folder per experiment ID of [`docs/EXPERIMENTS.md`](../docs/EXPERIMENTS.md):

```
results/exp01/
  command.txt        exact command(s), with the commit of this repository and of the submodule
  config.yaml        the Hydra config saved by the run
  metrics.json       written by the code, never typed by hand
  vram.csv           nvidia-smi memory log during the run
  run.log            stdout / stderr
  rollouts/          simulator videos; only small versions (*_small.mp4) are committed, full videos are linked
  figures/           regenerated by `python scripts/make_figures.py`
  notes.md           what was observed: successful and failed rollouts, one-line conclusion
```

Checkpoints, datasets and full-size videos are not committed (see `.gitignore`); their location and sha256 go into
`notes.md`.
